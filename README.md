# 수업료 정산 대시보드

구글 캘린더의 수업 일정을 월별로 집계해 수강생별 수업료와 인보이스(청구서)를 만드는 정적 웹사이트입니다. 서버 없이 GitHub Pages에서 동작합니다.

## 캘린더 일정 제목 형식

`수강생이름 - 과목` (예: `김민수 - 스페인어`, `이수진/영어`, `박지훈 영어`)

- 이름과 과목은 `-`, `/`, `_`, `,`, `:`, `|` 또는 공백으로 구분합니다.
- `휴강`, `취소`가 들어간 일정은 집계에서 제외됩니다. 제외 키워드는 사이트 설정에서 바꿀 수 있습니다.
- 제외된 일정은 화면 아래 "집계에서 제외된 일정"에서 확인할 수 있습니다.

## 1. 구글 OAuth 클라이언트 ID 발급 (한 번만)

1. https://console.cloud.google.com 접속 후 프로젝트를 새로 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Calendar API`를 검색해 **사용**으로 설정합니다.
3. **API 및 서비스 → OAuth 동의 화면**을 설정합니다.
   - 사용자 유형: 외부
   - 앱 이름, 이메일 입력
   - 게시 상태가 "테스트"이면 **테스트 사용자**에 본인 구글 계정(buyeon.hwang@gmail.com)을 추가합니다.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 원본**에 아래 주소를 추가합니다(끝에 `/`나 경로 없이 도메인만).
     - `https://yalli2.github.io`
     - 로컬 테스트용: `http://localhost:8000`
5. 발급된 **클라이언트 ID**(`xxxx.apps.googleusercontent.com`)를 복사합니다. 클라이언트 보안 비밀번호는 필요 없습니다.

## 2. GitHub에 올리기

1. GitHub(yalli2)에서 새 저장소를 만듭니다. 예: `tuition-dashboard` (Public)
2. 이 폴더의 `index.html`과 `README.md`를 저장소 루트에 올립니다.
   - 웹에서: 저장소 → **Add file → Upload files**
   - 또는 터미널:
     ```
     git init
     git add index.html README.md
     git commit -m "수업료 정산 대시보드 추가"
     git branch -M main
     git remote add origin https://github.com/yalli2/tuition-dashboard.git
     git push -u origin main
     ```
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정하고 저장합니다.
4. 1~2분 뒤 `https://yalli2.github.io/tuition-dashboard/`에서 사이트가 열립니다.

크리에이터링크 홈페이지에서는 이 주소를 링크로 연결하면 됩니다.

## 3. 처음 사용할 때

1. 사이트의 **설정**에서 클라이언트 ID를 붙여넣고 학원 정식 명칭, 입금 계좌, 하단 문구를 입력한 뒤 **설정 저장**을 누릅니다.
2. **구글 로그인**을 눌러 캘린더 읽기 권한을 허용합니다. (읽기 전용 권한만 요청합니다.)
3. 캘린더와 청구 월을 선택하고 **일정 불러오기**를 누릅니다.
4. 수강생별 **회당 단가**를 입력하면 청구 금액이 자동 계산됩니다. 단가는 이 브라우저에 저장되어 다음 달에도 유지됩니다.
5. **인보이스** 버튼으로 개별 청구서를, **전체 인보이스 보기**로 전원의 청구서를 만들고 **인쇄 / PDF 저장**으로 PDF를 저장합니다.
6. **CSV 내보내기**로 엑셀용 정산표를 받을 수 있습니다.

## 참고

- 설정, 단가, 클라이언트 ID는 브라우저 localStorage에만 저장되며 외부로 전송되지 않습니다. 다른 기기나 브라우저에서는 다시 입력해야 합니다.
- 캘린더 데이터는 브라우저와 구글 사이에서만 오갑니다.
- 로그인 토큰은 약 1시간 후 만료되며, 만료되면 다시 로그인하면 됩니다.
- 동의 화면이 "테스트" 상태이면 테스트 사용자로 등록한 계정만 로그인할 수 있습니다.
